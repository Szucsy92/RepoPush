# AGENTS
- Client-only Vite + React SPA, no server or router: everything ships as static files so it runs on GitHub Pages under any sub-path (`base: "./"`).
- GitHub access goes through the `GitHub` class in src/lib/github.ts, which takes the user's token explicitly and refuses any origin other than api.github.com; the CSP connect-src enforces the same.
- Commits use the Git Data API (blobs→tree→commit→force ref update) so ZIP replace/merge and patches are single atomic commits; destructive runs show a change-plan confirmation computed from git blob shas first.
- ZIP parsing and patch application run in the browser (src/lib/repo-files.ts).
- The Android APK is built by .github/workflows/android.yml: Capacitor shell generated in CI (`cap add android`, nothing Android-specific is committed), signed with a keystore generated once and stored AES-encrypted on the `signing` branch (password in the ANDROID_KEYSTORE_PASSWORD secret). The app detects the shell via src/lib/native.ts (no service worker, log copy instead of blob download).
- Service worker is generated by vite-plugin-pwa and registered only from src/lib/pwa.ts, which refuses dev and iframes.
